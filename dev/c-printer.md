# Reusable C printer verification

This work closes shared proof prerequisites for the existing adapter code. It
adds no Modelica or GALEC production and changes no emitted C bytes. The whole
compiler and FMI/eFMI conformance contracts remain open.

The numerical and tensor printers already connect their emitted fragments to
independent C grammars. The FMI reset certificate also covers a complete
function, but its syntax relation spells out that particular function. Further
adapter functions should instantiate shared syntax and printer theorems.

## Current increment

`Parser.Scanner.Prefix` gives compositional scanning judgments with the actual
remaining characters present. Composition preserves word/number maximal munch
and configured symbol boundaries. Complete prefixes agree with the existing
scanner relation. This adds a proof interface, not an executable C parser.
Its six new audit roots pass `build/source-cutover/build/c-printer/parser-audit.log` in the isolated
checkout (792 jobs).

`RumocaC.TreePreprocessing` proves stability under trigraph replacement and
physical newline splicing. Its `Stable` fragments compose without creating a
rewrite across a boundary. Arbitrary UTF-8 string payloads reuse the existing
`CString` escaping and literal proofs. The theorem covers every CTree
expression and statement constructor, parameter lists, signatures and complete
functions. Raw names and type strings must contain no question marks or
backslashes. This condition is weaker than lexical or typing validity.

The complete module and its 19 new roots pass the unchanged C package axiom
audit in `build/source-cutover/build/c-printer/c-audit-v1.log` (2161 jobs). `RuntimePreprocessing`
discharges the body precondition for every branch of the actual FMI emitter.
`AdapterPreprocessing` composes helpers, declarations, prefixes and public
functions into the complete `Runtime.render` result. The FMI package audit
passes in `build/source-cutover/build/c-printer/adapter-audit.log` (1211 jobs). Those package passes
cover 33 new roots across the parser and C/FMI packages.

The next composition strengthens `AdapterContract` with stability of the actual
file characters. Model-name safety follows from the existing parsed-name theorem;
signature spellings are checked using standard-library decidability in the
kernel certificate. A public consequence exposes the new file guarantee.
That composition and its two added roots pass the affected-package audit in
`build/source-cutover/build/c-printer/composed-package-audit.log` (2442 jobs).
The fixed `CheckFMI3Build.lean` passed on files extracted from the retained FMU
in `build/source-cutover/build/c-printer/actual-fmi.log`. All 35 added roots
retain the unchanged axiom policy. The required main artifact gate passed in
`build/c-printer/full-gate.log`, including both actual archives and the existing
native/mutation boundaries. All 596 inventoried inputs remained unchanged.
The exact archives and hashes are retained in `build/c-printer/artifacts/`.

## Standards correspondence and remaining work

The boundary/syntax increment now has generic expression, statement and
complete-function printer proofs. Its first 80 roots pass the parser/C package
audit in `build/c-token/function-audit.log` (2193 jobs). The earlier 46-root
token/grammar checkpoint is retained in `build/c-token/syntax-audit.log`.
`CPunctuator` lists all C11 punctuator spellings independently of the emitter
and proves longest-match boundaries, uniqueness and the actual binary-operator
renderer for arbitrary continuations. `CString.literal_prefix_free` and
`quote_boundary` prove ordinary literals have a unique closing boundary and
byte interpretation on the actual input. `CTree.Syntax.expression_start` and
`punctuator_before_expression` compose the punctuator result with arbitrary
CTree expressions having valid identifier leaves.

`CLexical`, `CIdentifierToken` and `CPPNumber` share source-character rules and
prove word/natural-number boundaries against conservative candidate grammars.
These include universal-name syntax and possible identifier extensions; they
do not assume every competing token was generated by our printer. `QuoteBody`
likewise proves unique closing boundaries in a larger quoted-body language,
then preserves the existing literal byte-value result. `CTokens.Prefix` composes
the token judgments with the actual suffix present, with guards for encoded
literal, dot-number and comment fusion. `TypeDenotation` supplies explicit
typedef context, selected type syntax and suffix-parametric lexical evidence
for primitive/typedef names, const qualification and pointers.
`Expression` gives independent C precedence classes, postfix restrictions and
unary/binary productions; `binary_grouped` relates each actual binary-operator
spelling to its intended parse. These are universal proofs; no executable C
parser, new test suite, source case or emitted-byte change is added.

`Printer.expression_renders` quantifies over every admissible expression tree
and safe actual continuation. The domain checks names and type spellings and
excludes unparenthesized `sizeof` in postfix positions and bare numeric field
bases. Those restrictions describe the unchanged renderer; they are not C
typing guarantees. `statement_renders` covers declarations, assignments,
expression/return statements, nested branches and loops at every indentation
depth. `function_renders` composes those proofs with scalar/array parameters,
explicit `(void)` prototypes and external/static definitions. The independent
grammar keeps C precedence and block-item restrictions. `function_denotes`
provides the whole-text consequence for artifact contracts.

`Reset.Printer.function_printable` instantiates the shared theorem on the actual
reset construction tree, with its required typedef context stated explicitly.
`Reset.FunctionContract` now additionally requires that generic grammar for
the certified text. Its existing syntax, complete-call and memory guarantees
are retained. `adapter_reset_syntax` locates that text inside the actual adapter
file bound by `AdapterContract`. This requires no function-specific token
skeleton in the new proof and no change to the emitted function.

The generic token/phrase contract is integrated into the actual reset file
certificate; it does not yet cover every adapter function or whole files.
Cross-category maximality and phase-six concatenation remain to be composed.
Actual typedef/header interpretation, scopes and execution contracts remain
open. Kernel checking of the
candidate grammars is distinct from review of their coverage against C prose.
All 85 added roots and the affected packages pass
`build/c-token/final-package-audit.log` (2459 jobs), with the unchanged axiom
policy. The required full gate passed in `build/c-token/full-gate.log`, including
both actual archives and the existing native/mutation boundaries. All 613
inventoried inputs remained unchanged throughout the run. Exact archives and
SHA-256 identities are retained in `build/c-token/artifacts/`.

The primary C reference is [WG14 N1570](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf).
Sections 5.1.1.2 and 5.2.1.1 describe the character rewrites modeled here.
Source/execution encodings, preprocessing directives and header meanings are
separate obligations; character stability does not establish them.
